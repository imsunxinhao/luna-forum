<p align="center">
  Luna Forum 是一个轻量，高性能的论坛系统，使用 TypeScript 和 MongoDB 构建。
</p>

---

## ✨ 特性

 - **快速的论坛系统**：采用 Fastify 作为 Web 服务器，使得 Luna Forum 具有高并发，速度快的特点。
 - **“小而美”的论坛系统**：微内核架构，插件定义一切。
 - **现代的论坛系统**：采用 Fluent UI Web Components，实现与众不同的界面。
 - **开放的插件支持**：简单，易开发。

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| [TypeScript](https://www.typescriptlang.org/) | 开发语言 |
| [Fastify](https://www.fastify.io/) | Web 框架 |
| [Nunjucks](https://mozilla.github.io/nunjucks/) | 模板引擎 |
| [MongoDB](https://www.mongodb.com/) | 数据库 |
